## 首个公开预览版

- 提供 Windows x64 安装版与干净的便携 ZIP。
- 接入 GitHub Release 签名更新，安装版可在应用中下载和安装；便携版提示下载 ZIP。
- mpv 播放核心改为从上游按需安装，支持打开目录、重装与卸载。
- 完善开源说明、使用帮助、第三方致谢和反馈入口。
- 包含在线搜索、多季查找、历史与收藏、缓存管理、倍速连播及全屏控制条。

### 首次使用

在「设置 → 模块与存储」安装 mpv，并导入你已有客户端的 `backend` 文件夹。公开包不包含原客户端私有播放服务、第三方视频或封面。AI 超分和插帧默认关闭，需另外安装模块；实时性能取决于设备。

### 升级

0.1.8 及更早的本地版需要先手动升级一次。便携版完整解压后运行；后续覆盖程序文件时保留 `data/` 与 `hongguo-storage.json`。

更新签名是应用内验证机制，不是 Windows Authenticode 代码签名。
