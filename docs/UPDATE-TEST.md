## 测试数据与核对方法

使用独立目录及虚构剧名，不向公开仓库提交个人记录。测试数据包括：

- 两条历史：第 7 集、43.25 秒；第 12 集、76.5 秒。
- 三条收藏，分别代表短剧、AI 剧和漫剧。
- 22 项偏好，包括 2 倍速、长按 3 倍速、15 秒跳转、关闭自动连播、软件解码，以及关闭增强与插帧。
- 浅色主题、展开侧边栏、三条中文搜索记录和三部本地剧库资料。

先在关闭的隔离 WebView2 测试数据库中准备记录，启动旧版确认显示，并通过旧版界面修改推荐偏好。升级前保存逻辑值快照；升级、关闭、冷启动后分别读取数据库，对历史、收藏、设置等逐项执行深度相等比较。界面同时确认收藏数量和历史中的集数。离线检查工具位于 [`scripts/update-e2e-data.mjs`](../scripts/update-e2e-data.mjs)，仅允许访问 `work/update-validation` 内的测试目录；不会为已压缩到 SST 文件的数据库猜测结果。

## 正式包与测试准备

起始可执行文件取自已发布的 v0.1.9，源码及更新逻辑没有为测试改写。为了与现有同名客户端隔离，将该文件放入测试安装目录，以安装版文件名运行，不放置便携版标记，并单独准备本项目的安装位置登记。此步骤用于建立旧版测试环境，**没有运行存在名称冲突的旧 v0.1.9 初装安装器**。

升级目标是公开 Release 上的真实 v0.1.10 安装包及 `latest.json`，软件自己检查、下载和调用安装器。确认旧进程退出，新进程由安装器启动，并运行在同一个测试安装目录。安装包内程序与便携包程序仅有 Tauri 的 `NSS` / `UNK` 包类型标记差异，其余字节一致。

## 实测发现并修复的问题

旧安装模板仅用软件名作为 Windows 卸载登记键，与同名客户端冲突。v0.1.10 改为使用 `app.hongguo.personal`，快捷方式添加 Aemeath 标识，默认安装目录增加 Aemeath 子目录。已有 Aemeath 安装位置仍可恢复；升级保留 `data` 及 `hongguo-storage.json`。

两轮升级前后，同名原客户端的卸载登记导出文件完全一致，抽查的原卸载程序哈希未改变。
